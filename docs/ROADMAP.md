# 咯咯牧场迭代路线

目标：先把“养鸡、繁育、探索”做成一个有短期决策和中期追求的放置游戏，再公开给朋友测试。

## V0.2 牧场成长（当前迭代）

- 设施：鸡舍、孵化器、繁育窝、仓库、训练场
- 设施升级消耗游戏内资源，并对产能、孵化、繁育、离线收益产生明确加成
- 牧场任务：引导玩家完成收取、孵蛋、组队和探索，奖励资源与闪光蛋
- 首页展示设施等级、下一阶段目标和可领取奖励

## V0.3 鸡只与繁育

- 扩充到 8-12 个品种、12-20 个词条
- 增加工作能力和战斗定位，让同一品种也有不同用途
- 增加词条锁定、突变线索、亲本谱系和图鉴
- 重复鸡转化为基因粉尘，避免收集结果完全浪费

## V0.4 探索与战斗

- 3 个区域，每个区域包含路线节点、资源点、事件和首领
- 用事件卡和自动战斗替代单纯倒计时
- 增加属性克制、队伍状态和一次性道具
- 探索专属产出：基因、图纸、稀有蛋和设施材料

## V0.5 内容与测试

- 主线任务、成就和图鉴完成度
- 新手首小时体验与离线收益平衡
- 移动端触控、存档迁移、异常恢复和性能检查
- 邀请朋友进行小范围测试，根据反馈调整数值和节奏

## 迭代原则

每一版只引入一组能改变玩家决策的系统。优先补足成长目标和资源消耗，再扩充鸡种、区域和演出；不以堆数量代替玩法深度。
